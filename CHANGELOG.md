# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0]

### Added

- Gemini CLI extension: `gemini-extension.json` and `GEMINI.md` at the repository
  root, with both remote MCP servers.
- GitHub Copilot plugin in `copilot-plugin/`: `plugin.json`, `mcp.json` and one
  skill.
- Cursor plugin: `.cursor-plugin/plugin.json` and `mcp.json` at the repository
  root.
- Apache License 2.0 text in `LICENSE`, and a README section that states which
  files it covers.
- A README section per client, and a table of the two MCP servers.

### Changed

- The Claude Code marketplace and plugin are now version 1.0.0 and carry
  homepage and repository fields.

### Removed

- The inherited `CODEOWNERS` file.
